# Tipografía Editorial y Jerarquía — Casa Encuentro

## 1. Familias Tipográficas
- **Familia Display / Títulos:** Editorial Serif de alta elegancia y serenidad orgánica (`Fraunces` o `Playfair Display` o `Cormorant Garamond` con fuentes fallback serif clásicas: `Georgia`, `serif`).
- **Familia Cursiva / Script:** Acento cálido y humano ("Pausa", "Te esperamos", "Con Mariano", "Silvana Camiño").
- **Familia Interfaz y Lectura:** Sans-serif abierta, legible a cualquier distancia y edad (`Plus Jakarta Sans` / `Outfit` / `Inter`, con fallback `system-ui`, `sans-serif`).

## 2. Jerarquía de Tamaños (Mínimo 16px para texto general)
- `Display Hero`: `text-4xl md:text-5xl font-serif text-forest-deep tracking-tight`
- `H1 Sección`: `text-3xl font-serif text-forest-deep`
- `H2 Subtítulo`: `text-xl md:text-2xl font-serif text-forest-deep/90`
- `H3 Tarjeta`: `text-lg font-semibold text-stone-900`
- `Cuerpo Regular`: `text-base (16px) leading-relaxed text-stone-700`
- `Labels y Metadatos`: `text-sm font-medium tracking-wide uppercase text-forest-deep/70`
